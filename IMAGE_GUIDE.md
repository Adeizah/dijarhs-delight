# Dijarhs Delights — Picture Guide

All website photos are kept together in the single `pictures/` folder. Each filename describes the product it belongs to.

## Change a picture
1. Open `pictures/`.
2. Replace the relevant image while keeping the exact same filename (for example, replace `awara.jpg` with your preferred Awara photo).
3. Keep the file as a JPG image and keep the filename unchanged. If you use a different filename or extension, update the matching `pictures/filename.jpg` path in the website code.
4. Upload the changed file(s) to GitHub and commit.
