# Dijarhs Delights — Website v2

A responsive three-page static website inspired by the approved visual direction.

## Pages
- `index.html` — Home
- `menu.html` — Menu
- `story.html` — Our Story, contact and FAQs
- `styles.css` — all visual styling
- `script.js` — mobile navigation and small interactions

## Preview
Open `index.html` in a browser. Internet access is needed for the Google Fonts and remote Unsplash images.

## Free GitHub Pages hosting
1. Create a public GitHub repository named `dijarhs-delights`.
2. Upload the five files above to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. Wait for the published URL to appear on the Pages screen.
