# Dijarhs Delights Website

A three-page static website for Dijarhs Delights. Includes Home, Menu, and Our Story/contact pages, local product photos, Instagram links, and WhatsApp enquiry links.

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload the contents of this folder to the root of your GitHub repository.
3. Open Settings → Pages, choose Deploy from a branch, select `main` and `/(root)`, and save.
4. See `IMAGE_GUIDE.md` if you ever want to replace any product photo later.


## Product pictures
All website photos are stored together in the `pictures/` folder with clear filenames. See `IMAGE_GUIDE.md` for the list and replacement instructions.
