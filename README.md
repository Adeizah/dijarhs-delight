# Dijarhs Delights website

A responsive three-page static website:
- `index.html` — Home
- `menu.html` — Menu
- `story.html` — Our story and contact

## Preview locally
Open `index.html` in a browser. Internet access is needed for Google Fonts and the remote Unsplash image URLs.

## Free hosting with GitHub Pages
1. Create a GitHub repository (for example, `dijarhs-delights`).
2. Upload the contents of this folder to the repository root (not just the ZIP).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub to publish the site and use the URL shown in Settings → Pages.

## Before publishing
- Replace the draft story text in `story.html` with the owner's real story.
- Replace the generic WhatsApp link with the owner's business number, in international format without `+`, spaces, or dashes. Example format: `https://wa.me/23480XXXXXXXX`.
- Add verified prices or keep “Ask for a quote”.
- Review every stock photo and replace any that don't accurately represent products sold.
- For an image URL, update the relevant `background-image` in `styles.css`.
- Check the website on mobile and desktop.

## Important
Product photography currently uses remote Unsplash images as visual placeholders. These are not claimed to be actual Dijarhs Delights products. Confirm image licensing and product accuracy before launch.
